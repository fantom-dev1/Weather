# 🌦️ Weather App  

## ✨ Overview  
A simple weather application built in a *glassmorphism* style.  
It provides detailed information about the current weather and shows a 7-day forecast.  
The project was created as a learning exercise, combining a modern interface with practical features.  

---

## 🛠️ Technologies  

**Languages:**  
- JavaScript  
- HTML  
- CSS  

**Libraries & Tools:**  
- React (v17.0.1)  
- Pirate Weather (weather data)  
- Geonames API (location search)  
- Weather Icons (icon set)  

**Development Tools:**  
- VS Code  
- ShareX  

---

## 🌍 Features  
- 📊 Detailed current weather data  
- 📅 7-day forecast  
- ⏰ Clock display  
- 🔍 Location search  
- 🌐 Language selection  
- 🪟 Modern glassmorphism design  
- 📱 Fully responsive layout

## ⚙️ Setup  

### Run locally  
1. Download or clone this repository  
2. Open the project in VS Code  
3. Install dependencies:  
   ```bash
   npm install
   ```  
4. Start the development server:  
   ```bash
   npm start
   ```  
5. Open the generated address in your browser  

### Deployment (GitHub Pages)  
1. Build the project:  
   ```bash
   npm run build
   ```  
2. Rename the `build` folder to `docs`  
3. In the generated `main.xxx.css` file, replace every `/static` with `../media/`
